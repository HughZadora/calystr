# Pi Adapter

Pi is the only Calystr V1 harness runtime. The extension targets the actively supported `@earendil-works/pi-coding-agent` package; the deprecated `@mariozechner/pi-coding-agent` scope must not be reintroduced.

The adapter translates compiled Calystr requirements into Pi extension, skill, advisor, policy and evidence context while preserving bounded handoff and user-only business judgement.
