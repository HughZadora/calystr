# Calystr Intent Resolution

Inspect the repository and available facts before asking questions. Use Calystr mappings and mature-solution knowledge to form recommendations.

For every question that genuinely requires user business judgement, provide options, a recommendation, reasoning and trade-offs. Do not ask users to choose frameworks, databases, testing tools, architecture patterns or other technical facts that the harness can determine.

Produce traceable Requirement and Capability context before implementation.
