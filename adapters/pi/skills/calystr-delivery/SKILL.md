# Calystr Delivery

1. Confirm the current Requirement and Capability graph.
2. Evaluate mature solutions before BUILD.
3. Treat Design as a first-class product artefact before implementation.
4. Plan verification from Requirement acceptance, not from existing tests.
5. Implement using design-before-code, appropriate TDD and root-cause debugging patterns.
6. Run external verification and normalise results into Evidence.
7. Keep evidence revision-scoped and reject stale evidence.
8. Use OPA as the final gate. UNKNOWN must never become PASS implicitly.
9. Use bounded Handoff for fresh agents and long-running work.
