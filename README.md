# Calystr

Commercial Product Standard Compiler — compile engineering, product design and verification knowledge into executable standards for Pi.

## Status

Phase 0 — repository and architecture foundation.

## Repository principles

- Architecture is established before feature implementation.
- Domain, runtime, compiler, policy, adapter and evidence boundaries are explicit.
- Changes are committed by logical architectural or functional unit, never one file per commit.
- Phase work must remain inside the established topology unless an Architecture Decision Record approves a structural change.

## Core specification

The repository follows the Calystr V1 freeze specification supplied for this project. Phase 1 establishes the domain foundation and repository topology before runtime or adapter implementation.
